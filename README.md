# Spear-dz Store

Algerian High-Tech e-commerce storefront (Cash on Delivery across 58 Wilayas) with React, Vite, Tailwind CSS, Vercel Serverless API, Supabase storage, and courier dispatch integration.

## Pages
- `/` — Pack High-Tech 5 en 1 (20,400 DZD)
- `/pack2` — Pack Sound & Power 4 en 1 (6,600 DZD)
- `/speaker` (`/pack3`) — Enceinte Bluetooth BS-232A + Microphone (4,500 DZD)
- `/admin` — Order & Logistics Management Portal

## Commands
```bash
npm install
npm run build
npm test
npm start
```
